# Sneha Rawat — Personal Portfolio

## Files
- `index.html` — page structure and content
- `style.css` — colours, layout, cards, and responsive styles

## Run locally
1. Keep both files in the same folder.
2. Open `index.html` in a modern browser, or use the VS Code Live Server extension.

## Before publishing
- The contact section is set to `sneharawat0408@gmail.com`.
- The two project cards are sample project ideas, not completed projects. Build them before claiming them as finished work.
- Check the page on mobile and desktop.

## Publish with GitHub Pages
1. Create a GitHub repository and upload both files.
2. Open the repository's **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. After deployment, copy the GitHub Pages URL into your submission form.
